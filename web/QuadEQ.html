Introduction

A quadratic equation is an equation of degree 2 in one variable. It can be written in the standard form:

ax² + bx + c = 0

where

  • a, b and c are real numbers.
  • a ≠ 0
  • x is the variable.

Examples

x² − 5x + 6 = 0

2x² + 7x − 4 = 0

x(x + 5) = 24

Methods of Solving

1. Factorisation

Factorise the quadratic expression and equate each factor to zero.

2. Completing the Square

Convert the equation into a perfect square and solve.

3. Quadratic Formula

Use the quadratic formula when factorisation is difficult.

Factorisation Method

Steps

  1. Write the equation in standard form.
  2. Factorise the quadratic expression.
  3. Equate each factor to zero.
  4. Find the values of x.

Example

x² − 5x + 6 = 0
(x − 2)(x − 3) = 0
x = 2 or x = 3
Roots = 2 , 3

Completing the Square

x² + 6x + 5 = 0
x² + 6x = -5
(x + 3)² = 4
x = -1 or -5

Quadratic Formula

x = (-b ± √(D)) / 2a

This formula can be used to solve every quadratic equation.

Discriminant

D = b² − 4ac
Value of D Nature of Roots
D > 0 Two distinct real roots
D = 0 Two equal real roots
D < 0 No real roots

Important Formulae

Sum of Roots = -b/a

Product of Roots = c/a

Applications

  • Area Problems
  • Rectangle & Square Problems
  • Number Problems
  • Speed and Distance
  • Geometry Problems

Board Exam Tips

  • ✔ Always write the equation in standard form.
  • ✔ Check your answer by substitution.
  • ✔ Use factorisation whenever possible.
  • ✔ Learn the quadratic formula thoroughly.
  • ✔ Remember the discriminant conditions.
