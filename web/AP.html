Arithmetic Progressions

Complete Class 10 CBSE Notes • NCERT Based • Board Exam Revision

Introduction

An Arithmetic Progression (AP) is a sequence of numbers in which the difference between any two consecutive terms is constant.

a, a + d, a + 2d, a + 3d, ...

This constant difference is called the common difference.

  • a = First term
  • d = Common difference
  • n = Number of terms
  • aₙ = nth term

Examples of AP

2, 5, 8, 11, 14, ...

20, 17, 14, 11, ...

3, 3, 3, 3, ...

In each of these sequences, the difference between consecutive terms remains constant.

Common Difference

The difference between two consecutive terms of an AP is called its common difference.

d = Second Term − First Term

d = a₂ − a₁

Example

7, 12, 17, 22, ...

d = 12 − 7

d = 5
Common Difference = 5

General Form of an AP

The terms of an Arithmetic Progression can be written as:

a, a + d, a + 2d, a + 3d, ...
Term Value
1st term a
2nd term a + d
3rd term a + 2d
4th term a + 3d
nth term a + (n − 1)d

nth Term of an AP

The nth term of an Arithmetic Progression is given by:

aₙ = a + (n − 1)d

where:

  • aₙ = nth term
  • a = first term
  • n = number of the term
  • d = common difference

Example

AP = 3, 7, 11, 15, ...

a = 3
d = 4
n = 10

a₁₀ = 3 + (10 − 1)4

a₁₀ = 3 + 36

a₁₀ = 39
10th Term = 39

Finding the Number of Terms

The number of terms can be found using the nth term formula:

aₙ = a + (n − 1)d

Example

5, 8, 11, ..., 50

a = 5
d = 3
aₙ = 50

50 = 5 + (n − 1)3

45 = 3(n − 1)

15 = n − 1

n = 16
Number of Terms = 16

Sum of First n Terms

The sum of the first n terms of an AP is denoted by Sₙ.

Sₙ = n/2 [2a + (n − 1)d]

where:

  • Sₙ = Sum of first n terms
  • n = Number of terms
  • a = First term
  • d = Common difference

Sum Using the Last Term

When the last term of an AP is known, we can use:

Sₙ = n/2 (a + l)

where l is the last term.

Example

2, 5, 8, ..., 29

a = 2
d = 3
l = 29

29 = 2 + (n − 1)3

27 = 3(n − 1)

n = 10

S₁₀ = 10/2 (2 + 29)

S₁₀ = 5 × 31

S₁₀ = 155
Sum = 155

Important Formulae

Common Difference:
d = a₂ − a₁

nth Term:
aₙ = a + (n − 1)d

Sum of n Terms:
Sₙ = n/2 [2a + (n − 1)d]

Sum using Last Term:
Sₙ = n/2 (a + l)

Applications of AP

  • Finding patterns in number sequences
  • Daily-life arrangements
  • Salary and savings problems
  • Seating arrangement problems
  • Finding sums of consecutive patterns
  • Word problems involving regular increases or decreases

Board Exam Tips

  • ✔ First identify the first term (a).
  • ✔ Find the common difference (d).
  • ✔ Write the correct formula before substituting values.
  • ✔ Be careful with negative common differences.
  • ✔ Check whether the question asks for a term or a sum.
  • ✔ Show all calculation steps in board exams.
